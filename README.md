## Средний уровень сложности

Добавлено 3 файла .py с решением заданий из индивидуального варианта.

**multiplication_table.py** соответствует заданию 1 — таблица умножения. Таблица реализована как матрица, где пересечение двух чисел в строке и столбце является их произведением. В коде функция вызывается с параметром по умолчанию (10 — базовый вид таблицы умножения-матрицы), при необходимости можно добавить в код ввод параметра размерности сетки вручную.

**factorial.py** соответствует заданию 3 — факториал числа. Реализация через цикл. Пользователю предложено ввести число при помощи консоли, реализована проверка значения и вывод сообщения об ошибке.

**primes.py** соответствует заданию 5 — cписок простых чисел до 100. Числа находятся при помощи простого алгоритма (перебор чисел и проверка делимости, делители ищем от 2 до корня из числа), хранятся и выводятся в виде списка. 

## Повышенный уровень сложности

Добавлено 2 файла .py с решением заданий повышенной сложности.

**bubble_sort.py** соответствует заданию 1 — сортировка списка методом пузырька. Реализация через двойной цикл: сравниваются соседние элементы и при необходимости меняются местами, если за очередной проход не было ни одного обмена, значит список уже отсортирован, и цикл прерывается. Функция возвращает новый список, не изменяя исходный.

**plot.py** — задание 4, построение графика функции y = x^2 с помощью библиотеки matplotlib. Значения x берутся от −10 до 10, y вычисляется возведением в квадрат. На графике: подписи осей, заголовок, оси через ноль, сетка, легенда. Результат сохраняется в **plot.png** для наглядности.
